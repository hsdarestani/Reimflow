# Phonetic lexical index

The generated, read-only SQLite index is deliberately not included in source control. The pinned build script verifies three source hashes and builds the index before packaging; there is no production network download or new Python dependency.

No dictionary definitions, affix rules or dictionary files are copied into the index; membership is used to select independently sourced IPA entries. Source is separately available at the pinned link.

Reproduce using `bash scripts/build-rhyme-lexicon.sh`. The SQLite file contains only spelling, IPA, derived phonetic keys and ordinal frequency rank. No song lyrics or subtitles are retrieved, stored or shown. Existing rights-gated artistic context remains separate.

Quality boundaries: dictionary entries are not guaranteed to be lemmas; language filters are conservative but cannot prove every word is not a proper name. Ambiguous or unknown pronunciations use the AI pipeline. No alphabetic suffix matching is used as phonetic evidence. The engine uses stress-to-end phonemes and a deliberately limited slant class; it does not claim acoustic similarity or calibrated probabilities. Phrase naturalness continues to require independent review. Full-phrase labels require additional vowel sequence evidence. Lowercase dictionary words without POS metadata use the existing Sonstiges category rather than invented POS.
